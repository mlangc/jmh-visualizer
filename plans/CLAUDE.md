# Implementation plans

- Name a plan `YYYY-MM-DD-<NAME>-PLAN.md`, with the date it was written and
  the name in upper kebab case, e.g. `2026-10-20-SCROLLABLE-SIDEBAR-PLAN.md`.
- Give it a "Ground rules" section that states how its commits reference it:
  a terse summary as the title, the plan's path (e.g.
  `plans/2026-10-20-SCROLLABLE-SIDEBAR-PLAN.md`) as the body and nothing else
  (see "Commit messages" in the root `CLAUDE.md`).
- Don't rename a plan once commits reference it.
